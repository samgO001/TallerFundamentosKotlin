Taller Fundamentos de Kotlin

Autor: Samuel Guarín

 Descripción

Este repositorio contiene un taller práctico compuesto por 30 ejercicios, cuyo propósito es fortalecer y consolidar los conocimientos fundamentales del lenguaje de programación Kotlin.

El contenido está organizado en seis bloques temáticos que permiten un aprendizaje progresivo, abordando desde conceptos básicos hasta estructuras más completas del lenguaje. Cada bloque incluye ejercicios diseñados para poner en práctica lo aprendido de manera clara y estructurada.

El archivo Main.kt funciona como punto de entrada del programa, desde donde se pueden ejecutar los diferentes ejercicios desarrollados en cada bloque.

 Contenido por Bloques
 Bloque 1 – Variables y Tipos de Datos

Se estudia la declaración de variables utilizando val y var, el uso de tipos de datos explícitos, la inferencia de tipos y la definición de constantes.

 Bloque 2 – Null Safety

Se trabajan mecanismos de seguridad para el manejo de valores nulos, incluyendo variables nulables, operador Elvis (?:), llamadas seguras (?.) y el uso de let.

 Bloque 3 – Condicionales

Se abordan estructuras como if (incluyendo su uso como expresión) y when, permitiendo evaluar múltiples condiciones, valores y rangos.

 Bloque 4 – Ciclos y Bucles

Se implementan estructuras repetitivas como for, junto con modificadores como downTo y step, además de ciclos while y do-while.

 Bloque 5 – Funciones y Parámetros

Incluye la creación de funciones con retorno, funciones de una sola línea, parámetros por defecto y argumentos nombrados.

 Bloque 6 – Colecciones y Extensiones

Se introduce el uso de listas mutables, así como funciones como filter y find, además de funciones de extensión.
